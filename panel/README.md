# Панель BSL Compass Pro

Vue 3 + Vite SPA: обзор, конфигурации, «Живые данные» (офлайн-обмен 1С),
бэкапы, журнал вызовов, настройки.

## Сборка

```bash
npm ci          # строгая проверка lock-файла
npm run build   # → dist/ ; Dockerfile собирает панель node-стейджем (npm ci + npm run build)
```

Ядро отдаёт `dist/` по `/ui`; если панель не собрана — заглушка
«Панель не собрана» из `src/panel_page.py` с подсказкой команд.
